# Grey Gamboa · Barbería

**Sitio en producción:** https://morado.greygamboa.pages.dev/

Landing para una barbería en Bosa Porvenir, Bogotá, con reserva online, y un panel para que el dueño administre su página sin tocar código. Desarrollada por **Mussav Studio**.

> El código es privado por acuerdo con el cliente. Este repositorio es un caso de estudio.

## Qué incluye
- Landing con servicios, galería y enlace de reserva.
- Panel para editar precios, promociones y reseñas.
- Conteo de clics para ver cuánto tráfico trae la página.
- Imágenes optimizadas.

## Stack
Cloudflare Workers · Cloudflare D1 · HTML, CSS y JavaScript

## Mi rol
Desarrollo completo: página, panel, Worker y base de datos.
